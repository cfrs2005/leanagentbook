## 测试覆盖的具体保证

1. Markdown 的行号、父段范围、子段范围和版本可追溯；中文表格原文保留。
2. HTML 脚本不入库，正常文字能以源代码行号定位。未声称计算 CSS 可见性。
3. 同一内容幂等；更新后旧词不可检索，旧缓存失效；指纹和解析使用同一份字节快照。
4. 删除清空当前文档的父段、子段、词项和上下文；另一个连接提交删除后，先前句柄拒答。重新入库不复用旧版本号。
5. 权限在候选计算前过滤，回答时再检查；权限变化使既有句柄失效。身份参数是测试模拟，不含认证实现。
6. 未命中、伪造句柄、失效句柄、预算不足均拒答。
7. 恶意资料可被原样摘录，但不能执行指令、改变权限或获取受限内容。这仅适用于没有模型和工具执行器的本脚本。
8. PDF 为 reportlab 生成的真实一页文本 PDF；pypdf 能取出 14 days 与页码。空白页要求 OCR，损坏结构抛错。
9. 失败解析保留上一有效版本；关闭并重新打开 SQLite 后可检索。
