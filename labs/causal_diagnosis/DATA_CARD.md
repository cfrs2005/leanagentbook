# 合成数据卡：synthetic-motor-v1

## 来源和用途

全部数据由本目录 `diagnosis.py` 生成。没有设备记录、采访、个人信息或企业故障统计。用于验证计算和教学流程，禁止将输出解释为真实电机故障概率。

## 模式与结构

一行代表一个独立合成电机状态，无时间序列、无单位、无实际传感器阈值。字段值 1 表示状态存在，0 表示不存在。

| 字段 | 含义 | 人为条件概率 P(字段=1) |
| --- | --- | --- |
| load=L | 高负载，不一定是故障 | 0.4 |
| bearing=B | 轴承故障 | 0.12 |
| cooling=C | 冷却故障 | 0.15 |
| current=I | 电流高 | 0.05 + 0.55L + 0.25B |
| temperature=T | 温度高 | 0.05 + 0.35L + 0.25B + 0.30C |
| vibration=V | 振动高 | 0.05 + 0.70B + 0.10L |
| id | 种子与行号 | 仅用于拆分核对，不输入推断 |

每个变量有独立 U∼Uniform(0,1)，结构方程为 X=1[U_X < P(X=1|parents)]。根变量独立；B 与 C 可同时存在。没有未观测共同原因、反馈回路、测量误差或模型外故障，这些都是强假设。CPT 全部为人工设定；没有训练集，因为没有从数据拟合 CPT。

## 拆分与校准

校准集 seed=2201，1000 行；测试集 seed=2202，1000 行。两集合独立随机流、ID 不重叠；相同六位状态可以重复，并不构成实体泄漏，因为生成器独立生成新个体。推断只使用 I/T/V，B 作为评测标签，L/C 不进入评测特征。

校准集选择 shrink∈{0,0.25,0.5,0.75,1}，变换为 `(1-shrink)*posterior + shrink*0.12`，最小化 Brier 分数。随后冻结参数，在测试集报告原始与校准后 Brier 和固定五个可靠性箱。空箱输出 null，不声称完美校准。没有用测试结果选参数。

这是同一生成器内的校准演示，非外部有效性检验。选择 0 表示保留原始后验，不说明真实数据无需校准。测试集有限，分箱频率存在抽样波动；报告不提供现场准确率或置信区间。

## 反事实与证据限制

完整事实状态使每个 U 的后验成为对应区间。温度反事实仅支持 do(load)，保留同一 U_T 后验区间及 B/C。已知 U 的演示保留全部同一 U；它不表示实际设备能观测这些噪声。

诊断样例只提供三个合成症状；来源标签不是身份信息。缺失变量被边缘化，矛盾记录直接阻止推断，不默默选最新一条。真实时间戳、传感器质量和数据授权不在本实验范围。
