```sh
python3 -m unittest discover -s labs/observability -v
python3 labs/observability/observability.py --output labs/observability/example-run
```

## 测试证据范围

| 范围 | 检查内容 |
|---|---|
| 关联与隔离 | 成功父链、嵌套父链、跨 trace 创建拒绝、两个并发任务上下文隔离 |
| 脱敏 | 不允许字段、非法取值、异常原文、运行中添加的属性均不导出 |

| 篡改 | 任意命令、非法 effect、HTML 脚本文本属性被拒绝 |
| 指标 | 1–100、单样本、空样本分位数；失败分母；重复 trace 聚合拒绝；未知值保留 |
| 产物 | HTML 无脚本和远程资源，CLI 子进程真实导出并回放 |
