# 数据卡：合成客服与设备检索集 v1

- 创建日期：2026-11-20。作者为本课程贡献任务；全部文本由课程作者合成，无客户数据、企业事实或访谈。E104/E140 是虚构产品的教学定义，不能用于真实设备诊断。
- 32 篇英文短文，28 个英文查询，10 个开发查询、18 个测试查询。英文用于适配本实验固定的英语模型，不说明中文效果。语料文件见 [corpus.json](corpus.json)，标注见 [judgments.json](judgments.json)。
- 覆盖：同义改写、词面匹配、多条件、否定、错误码、权限、相近但错误的操作。不是从答案文本机械复制全部查询；但作者知道语料，可能存在措辞和场景偏差。
- 标注单位是查询与完整短文。2 分：直接回答主意图或给出关键操作；1 分：有用的补充依据，不能单独完整回答；0 分：无关、仅同主题或操作不符。JSON 只保存正例，未列出文档按 0 分处理。作者对每个查询按这份规则审阅固定的全部 32 篇语料；没有第二位独立标注者，未测一致性。
- 例如 q08 要下载账单而不退款，d08=2，讲退款的 d07=0；q18 要防止跨租户泄漏，d20 和 d31 均为 2，d15=1。q20 的 d21 含 E140 说明，但焦点为 E104，故为 1，主讲 E140 的 d22 为 2。此类分级可争议，必须在业务迁移时复核。
- 检索函数只接收文档与查询文本，不接收标签；标签仅在排序完成后用于计分。手工概念词表用于离线算法教学，不是学得的语义 embedding，其构造也受合成领域选择影响。
- 开发/测试划分在运行前写入文件；本次没有用测试分数调权重。所有方法固定候选深度 10、K=5、RRF 常数 60、加权融合权重 0.5。两组共用语料与领域，查询间存在关联，不属于严格的领域外泛化评估。
- 没有无答案查询；Recall/MRR/NDCG 对无正例查询直接拒绝，不能据本报告承诺拒答能力。扩展时应单列无答案集，测误召回/拒答，不把其指标填为 1。
- 语料与标注按仓库许可发布。预训练模型权重不随仓库发布，其许可按各模型卡执行。

## 评测协议

对每个查询分别运行 BM25、Dense、RRF、逐查询 min-max 加权融合、RRF 后重排。BM25 使用全部语料的文档频率，英文小写正则分词，不去停用词、不做词干化。查询内重复词去重；全文扫描是教学实现，不代表倒排索引性能。Dense 使用完整短文向量做精确扫描，不使用 ANN。

每路取前 10，融合后取前 10，重排只改变这 10 篇的次序。无命中时仍可有 0 分文档进入候选，且按 ID 排同分；生产系统应额外设计阈值与拒答。Recall@5 的正例阈值为 grade>0；MRR@5 找前 5 个中的第一个正例；NDCG@5 的增益是 2^grade-1，折扣为 log2(rank+1)，IDCG 从全部正例计算。所有质量指标按查询宏平均，不按重复运行重复计数。candidate_recall 为候选前 10 的 Recall。

每条完整路径预热一次。每查询每方法串行运行 3 次，计时用 perf_counter，p50 为中位数，p95 为排序后 ceil(0.95*n) 位置。预训练模式的 Dense 包含查询编码，RRF/weighted 包含两路召回与融合，rerank 还包含成对模型推理。文档编码与模型加载分别记录，不进入查询延迟。模式内部路径都重新计算，不复用别的方法的查询结果。无网络服务延迟、并发或生产规模压测；54 个测试时延样本不足以稳定估计线上尾延迟。
