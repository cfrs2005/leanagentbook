# 08｜术语词典初始清单

| 英文术语 | 中文建议译法 | 所属章节 | 必须解释的重点 |
|---|---|---:|---|
| Token | 词元 | 1、5 | 文本切分单位，不等同于汉字或单词 |
| Embedding | 向量表示/嵌入 | 1、5、9 | 将对象映射为向量；区分 Token Embedding 与检索 Embedding |
| Attention | 注意力机制 | 5 | Q/K/V、权重和上下文关系 |
| Agent Loop | 智能体执行循环 | 2 | 决策、工具执行、观察和终止 |
| Runtime | 运行时 | 3 | 执行生命周期与资源管理 |
| Harness | 执行框架/护栏层 | 3 | 上下文、工具、策略和约束 |
| Workflow | 工作流 | 4、16 | 确定性步骤编排 |
| Checkpoint | 检查点 | 3、16 | 保存可恢复状态 |
| Durable Execution | 持久化执行 | 16 | 跨进程/故障恢复的长任务执行 |
| Dense Retrieval | 稠密检索 | 9 | 语义向量召回 |
| Sparse Retrieval | 稀疏检索 | 9 | 关键词/稀疏权重召回 |
| RRF | 倒数排名融合 | 9 | 多路排序列表融合 |
| Reranker | 重排序模型 | 9、10 | 对候选结果做更精细相关性排序 |
| SFT | 监督微调 | 6 | 使用示范样本训练模型 |
| LoRA | 低秩适配 | 6 | 以少量可训练参数适配模型 |
| DPO | 直接偏好优化 | 6 | 使用偏好对优化模型 |
| GRPO | 组相对策略优化 | 6 | 组内相对奖励/优势优化 |
| KV Cache | 键值缓存 | 5、7 | 缓存历史注意力 K/V |
| TTFT | 首 Token 延迟 | 7、8 | 请求到首个输出 Token 的时间 |
| TPOT | 每输出 Token 时间 | 7、8 | 生成阶段平均每 Token 时间 |
| Golden Dataset | 金标数据集 | 14 | 有可信标准答案/标签的评测样本 |
| Trajectory Evaluation | 轨迹评测 | 14 | 评估 Agent 执行步骤和工具行为 |
| Trace | 链路追踪 | 15 | 一次请求跨模块执行的记录 |
| Idempotency | 幂等性 | 16、18 | 重复执行不产生额外副作用 |
| PEP | 策略执行点 | 17 | 在动作执行前落实授权决策 |
| Time Series | 时间序列 | 19 | 按时间顺序采样的数据 |
| FFT | 快速傅里叶变换 | 19 | 从时域分析频域成分 |
| ROS Bag | ROS 数据包/录制文件 | 20 | ROS 消息记录与回放 |
| Edge Inference | 边缘推理 | 21 | 在设备或近端算力执行模型 |
| Causal Graph | 因果图 | 22 | 表达变量之间的因果关系假设 |
