# 07｜建议学习路线与验收里程碑

本路线不是要求 8 周内成为所有领域专家，而是用 8 个学习周期建立第一轮可验证能力。每周时间可按实际工作调整。

| 周次 | 学习主题 | 重点章节 | 最小产出 |
|---|---|---|---|
| 1 | 模型原理与训练 | 1、5、6 | Attention Demo + LoRA 实验 |
| 2 | Agent 与 Runtime | 2、3、4 | Mini Agent + Mini Harness |
| 3 | RAG 与多模态 | 9、10、11 | Hybrid RAG Demo |
| 4 | 数据工程 | 12、19 | 传感器数据 Pipeline |
| 5 | 评测与可观测性 | 14、15 | Golden Set + Trace Dashboard |
| 6 | 可靠执行与安全 | 16、17、18 | Durable Worker + Tool Gateway |
| 7 | ROS 与 Edge AI | 20、21 | Bag Parser + Edge Inference |
| 8 | 因果诊断与综合架构 | 22、23、24 | Robot Diagnosis Capstone |

## 每周验收

1. 能不看资料解释本周核心概念；
2. 能画出一张关键架构图；
3. 至少完成一个可运行实验；
4. 写出一个真实工程问题和设计取舍；
5. 更新术语表和未解决问题清单。

## 进度状态建议

- Not Started：未开始
- Researching：资料研究
- Drafting：正文撰写
- Implementing：工程实践
- Reviewing：技术审查
- Accepted：验收通过
